Thoth privacy policy

Last updated: August 17, 2026

Thoth is a local-first writing assistant. It does not create accounts, ads, or a central cloud of your writing.

What we handle

  • Text you type or select in editable fields
  • Settings (theme, length, tone, complexity)
  • Optional profile fields you add
  • Optional API keys if you choose API mode

Password, payment, and similar sensitive fields are ignored.

How it is used

Only to provide grammar, rewrite, and generate. We do not sell data or use your drafts to train public models.

Where it goes

By default, text is sent only to Thoth on your computer (http://127.0.0.1:8000) and local Ollama. If you opt into API mode, rewrite/generate go through that local server to the provider you configured. API keys and profile fields stay in Chrome storage on this device.

Control

Remove saved profile fields, API keys, or the extension at any time. Uninstalling removes extension storage.

Product policy

You own the text you enter. Suggestions are assistance only — review them before you send. You choose Local or API mode. Use Thoth in line with the sites you write on and any school or workplace rules that apply to you.

Thoth is provided as-is. Writing suggestions can be wrong.
